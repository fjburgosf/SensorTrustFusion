# Datasets

Synthetic datasets generated by SensorTrust Fusion (no hardware involved).
Each dataset is reproducible from its configuration and seed:

    python -m sensortrust generate-dataset configs/abrupt_bias.yaml -o datasets --name st_bench_02_abrupt_bias

Columns: `time`, `true_<state>`, `input_<u>`, `<sensor>`, `fault_<sensor>`,
`truebias_<sensor>`, `truevar_<sensor>`, `clean_<sensor>`; the companion
`*_meta.json` stores the seed, the SHA-256 fingerprint, the model, the sensors
and the fault ground truth. They can be re-imported (Export tab or
`python -m sensortrust import-dataset`) to reproduce published analyses.
